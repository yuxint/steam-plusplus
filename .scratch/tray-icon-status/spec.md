# spec: 菜单栏图标状态可视化 + 启停菜单一级合并

来源：grill-with-docs 评审（2026-09-17），用户逐条确认。

## 需求

1. 菜单栏图标直观体现加速状态：未加速时置灰。
2. 启动/停止加速不再放二级菜单，直接放一级。
3. 启动与停止合并为一个菜单项。

## 评审定案（Q1–Q5 均按推荐）

| 问题 | 定案 |
|---|---|
| Q1 图标置灰形式 | 单色 template image：加速中正常显色（随菜单栏深浅自动反色），未加速降 alpha 灰显；放弃彩色 logo 两态 |
| Q2 菜单项文案 | 随状态切换：启动加速 ↔ 停止加速，启动过渡期显示「正在启动加速...」并禁用点击 |
| Q3 原「网络加速」子菜单 | 删除，一级直接放合并后的单项 |
| Q4 附加信息（分组/时长） | 不加，保持极简 |
| Q5 启动过渡图标 | 不做第三态，两态即可（过渡归灰侧，菜单禁用表达过渡） |

## 实现

见 `docs/adr/0002-tray-template-image.md` 决策 2-5。

## 验收（2026-09-17 装机实测）

- 加速中：图标实心亮白、菜单「停止加速」、hosts 写入、443 监听 —— 通过
- 点击停止：图标变灰、菜单变「启动加速」、hosts 还原、443 关闭 —— 通过
- 再点击启动：图标恢复亮白、hosts 重写入、443 恢复监听 —— 通过
- 菜单结构：启动/停止加速（一级）→ 分隔线 → 打开主面板 → 分隔线 → 退出 —— 通过（System Events 枚举确认）
